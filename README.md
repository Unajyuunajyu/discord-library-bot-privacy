# 司書Bot Privacy Policy

このrepositoryはDiscord司書Botの公開Privacy Policy専用です。Bot本体repositoryとは分離し、公開対象はPrivacy site assetsのみとします。

`index.html` が公開Policyのcanonical sourceです。buildやdependencyは不要で、ファイルをbrowserで直接開いて読めます。JavaScript・外部font・analytics・formは使用しません。

## Privacy Policy

公開URL：<https://Unajyuunajyu.github.io/discord-library-bot-privacy/>

施行日・最終更新日：2026年9月28日。問い合わせ方法は当Discordサーバー管理者へのDiscord DMです。

## 配信構成

GitHub PagesのDeploy from a branch、main、/(root)を使用する構成です。custom Actions workflowはありません。remote操作・公開更新はProduct Ownerの明示承認が必要です。

公開前にplaceholderを実値へ置換し、未公開候補の注記を除き、本文・表示・連絡先・公開差分を確認します。施行日は実際の公開日とし、予想日を確定値として扱いません。公開後はHTTPS/login不要/mobile・desktopでの到達性を確認します。

## 保守

機能変更時はBot側のPrivacy Impact Checkに従い、必要な場合のみこのHTMLとBot側の実装対応文書を整合させます。local編集の許可は公開の許可ではありません。pushによりPagesが更新され得るため、毎回公開差分について明示承認を得ます。

ページ自身はcookie・localStorage・trackingを実装しません。hosting提供者の処理とは区別し、公開時に確認します。Bot source・設定・データ・logsをこのrepositoryへコピーしません。
